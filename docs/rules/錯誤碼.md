## 使用規約

- 本表為全系統**唯一錯誤碼來源**，數字錯誤碼用於 response envelope 的 `code` 欄位（見《RESTful API 設計指南》§7.2 / §9）。
- 成功一律 `00000`。
- 分段語意：`Axxxx` 用戶端錯誤（4xx）／`Bxxxx` 系統錯誤（5xx）／`Cxxxx` 呼叫第三方錯誤（5xx／502/504）。
- HTTP status 對映：`00000`→200；`A*`→400/401/403/404/409/429；`B*`→500；`C*`→502/504（逐碼定稿於 SD 階段）。

## 待補（SD 階段）

完整碼表將於 **SD 階段**補齊，涵蓋四服務實際錯誤面：auth（註冊/登入）、campaign（機率總和、銘謝惠顧缺失、次數超限 429、冪等衝突 409、狀態機衝突）、gateway（401/429/400）、inventory（庫存不足補償）。目前僅 auth 骨架。
