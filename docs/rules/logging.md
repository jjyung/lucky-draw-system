# Logging（日誌規約）

## 1. 框架

- 使用 **SLF4J 介面 + Logback 實作**（Spring Boot 預設），不自建日誌框架。

## 2. 級別

| 級別 | 用途 |
|------|------|
| ERROR | 系統錯誤，不可恢復 |
| WARN | 可能導致異常的警告（如庫存補償告警） |
| INFO | 關鍵操作與狀態變化 |
| DEBUG / TRACE | 除錯（**生產環境禁止**） |

## 3. 格式

- 使用佔位符 `{}`，避免字串拼接（效能）。
- 異常記錄：`log.error("msg", e)`，確保堆疊完整。

## 4. 敏感資訊

- 禁止記錄密碼、憑證、身分證號等；必要時脫敏。

## 5. 可觀測性

- 補償/告警路徑（如 inventory 庫存不足補償，`FR-INV-03` / `NFR-06`）需以 WARN/ERROR 留下可追蹤記錄。
